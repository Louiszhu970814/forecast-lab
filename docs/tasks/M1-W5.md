## 已確認的事實（協調者 2026-10-31 以 agy 1.4.12 實測，樣本在工作目錄的 `review_inputs/agy/`）

- `--settings` 遇到不認得的鍵會直接失敗：`Error: --settings: unknown setting "use_ai_credits"`，exit 1。所以只能傳 `useG1Credits`，PLAN §7.3 的雙鍵寫法要修正。
- `useG1Credits: false` 可以接受。`agy -p "/config" --output-format json --settings '<JSON>'` 會回傳實際生效的設定（`command.data.config`），樣本中可以看到 `agentMode: ""`、`useG1Credits: false`、`allowNonWorkspaceAccess: false`，以及完整的 permissions。
- log 的「CLI settings initialized」一行只列出 `--settings` 中的權限規則，沒有列出全域設定裡的 `command(agy)`。這表示 session 設定可能取代、而不是合併全域權限，但還需要以 `-p "/permissions"` 確認（V8）。
- 被 `deny` 規則擋下的指令：模型會收到「Matches user-configured deny rule」並在回答中說明，整次執行仍是 `SUCCESS`，而且 JSON 中沒有 `denied_actions`。前一次在 ask 規則下被自動拒絕的讀檔，則會讓執行結束，並出現在 `denied_actions`（`review_inputs/agy_r4a.json`）。兩種拒絕的證據來源不同，parser 要分開處理。
- 用 `gemini-3.8-flash-low` 時，模型回答「沒有可以開網頁的工具」，沒有開啟任何網頁。原因還不清楚：可能是模型沒有使用工具，或是 `read_url` 的工具在這個設定下不可用。請從 log 與 JSON 找線索並在回報中說明；本機實測由協調者執行。
- `/usage` 的 JSON：讀 `command.data.groups[].buckets[].remaining_fraction`。實測中，Flash 的執行只讓 `gemini-weekly` 與 `gemini-5h` 減少。
- log 中會有 `Propagating selected model override to backend: label="Gemini 3.8 Flash (Low)"`，可以作為模型判斷的輔助證據（PLAN §7.7）。

## 交付物

- `src/adapters/gemini.py`：
  - `build_argv`：依 profile 組參數，依 PLAN §5.3 加上 `--log-file <raw_dir>/agy_cli.log`；不使用 `--mode`。
  - `--settings` 的 JSON 由程式組成：
    - `tier1` 與 `acceptance`：`{"agentMode":"","useG1Credits":false,"permissions":{"allow":["read_url(*)"],"deny":["command(*)","write_file(*)","read_file(*)","execute_url(*)","mcp(*)","read_url(metaculus.com)"]}}`
    - `format_repair`：所有工具動作都拒絕。
    - `tier2`：最小自訂 agent（PLAN §7.3）的定義檔由程式寫到暫存資料夾，參數保留，預設關閉。
  - `parse`：
    - 讀取 JSON 外框（`status`、`error`、`finished_reason`、`denied_actions`、`structured_output`、`usage`、`num_turns`）。
    - 依 PLAN §5.5 的表格對應 token 欄位。
    - 從 log 擷取模型標籤與拒絕紀錄；兩種拒絕都整理成 `denied_actions`，並標明來源。
    - 判斷 `completed`：`status` 為成功、`finished_reason` 為空、回覆不是空的。
  - `cli_version`：取 `agy changelog` 的第一行，去掉結尾的冒號。
- `src/quota.py`：
  - `snapshot()`：執行 `agy -p "/usage" --output-format json` 與 `agy -p "/credits" --output-format json`，回傳各額度桶的 `remaining_fraction`、重置時間，以及 `remaining_credits`。
  - `judge(before, after, expected_bucket)`：依 PLAN §7.7 回傳 `verified`、`mismatch`、`unverified` 或 `undetermined`；同時有其他 agy 使用中、可能混入額度時，回傳 `undetermined`。
  - `credits_ok(snapshot)`：`remaining_credits` 必須為 0（D54）。
- `tests/test_adapter_gemini.py`、`tests/test_quota.py`，以及 `tests/fixtures/gemini/`：以 `review_inputs/` 的樣本製作精簡版 fixtures。
