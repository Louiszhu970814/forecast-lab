## 流程

1. 協調者為每個工作寫任務說明 `docs/tasks/M1-Wn.md`：目標、交付物、驗收條件，以及需要閱讀的 PLAN 章節。執行者只讀這些內容，不讀整份 PLAN。
2. 執行者在專案的 clone 中以代理開發模式工作（PLAN §7.1）：可以寫檔與執行測試，但不讀取網頁。
3. 審查者只看 diff、測試結果與任務說明，意見寫進任務說明的「審查紀錄」。
4. 審查通過後，由協調者合併、commit 並 push（D57）。
5. 需要真的呼叫三家 CLI 的測試與驗收，由協調者在本機執行。驗收使用 `config/run_config_v2.json` 的 `acceptance` 設定（D55）。

## 開發規則

- 執行期程式只用 Python 標準函式庫；測試使用 pytest。
- 不讀取 `.env`、任何 CLI 的登入憑證，或使用者全域設定的內容；測試只使用暫存的假檔案。
- 單元測試用事先錄好的 CLI 輸出樣本，不呼叫模型。
- 遵守 AGENTS.md 的開發慣例：Python 3.11 以上、JSON Lines 只追加不覆寫、時間一律記錄為 UTC 的 ISO 8601。
