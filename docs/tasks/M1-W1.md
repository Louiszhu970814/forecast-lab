## 目標

建立專案骨架與共用工具，後續所有模組都從這裡匯入。執行期程式只用 Python 標準函式庫（3.11 以上）。

## 交付物

### 1. 專案設定

- `pyproject.toml`：
  - 專案名稱 `forecast-lab`，`requires-python = ">=3.11"`；
  - 選用依賴 `dev = ["pytest"]`；
  - pytest 設定：`testpaths = ["tests"]`、`pythonpath = ["src"]`。
- 建立目錄 `config/`、`prompts/`、`src/flab/`、`src/adapters/`、`tests/`、`launchd/`；空目錄放 `.gitkeep`。不要建立 `data/` 與 `reports/`，這兩個在執行時才建立，而且不進版本控制。

### 2. 共用套件 `src/flab/`

| 模組 | 內容 |
|---|---|
| `timeutil.py` | `utc_now()` 回傳帶時區的 UTC `datetime`；`to_iso(dt)` 輸出 `YYYY-MM-DDTHH:MM:SS.mmmZ`；`parse_iso(s)` 接受 `Z` 與 `+00:00`，不接受沒有時區的時間。 |
| `ids.py` | `new_id(prefix)`：前綴加上依時間排序的唯一字串（毫秒時間戳加隨機數）；`canonical_json(obj)`：`sort_keys`、緊湊分隔符號、`ensure_ascii=False`；`sha256_hex(data)`；`hash_obj(obj)`，即 canonical JSON 的 SHA-256。 |
| `jsonl.py` | `append_record(path, record)`：<br>・以 `O_APPEND` 開檔，一次 `os.write` 寫入一整行，再 `fsync`；<br>・以 `fcntl.flock` 取得獨占鎖，必要時建立上層目錄；<br>・不提供任何覆寫或刪除紀錄的函式。<br>`read_records(path, strict=True)`：逐行解析；遇到無法解析的行，回報行號並丟出例外；`strict=False` 時只容忍最後一行不完整（寫入中斷），並回報該行。 |
| `runner.py` | `run(argv, *, cwd, stdin_text=None, timeout_s, stdout_path, stderr_path, keep_env=())`，回傳 `RunResult`。規格見下方。 |
| `workdir.py` | `make_attempt_dir(base=None)`：<br>・在專案資料夾以外建立名稱隨機（`secrets.token_hex`）、權限 `0700` 的資料夾；預設位置是 `tempfile.gettempdir()/flab-runs/`；<br>・路徑若位於專案資料夾之內，或已經存在，就丟出例外。<br>`remove_attempt_dir(path)`：只刪除位於 base 底下的資料夾。 |
| `envfile.py` | `load_env_file(path)`：解析 `KEY=VALUE`，忽略註解與空行，不做 shell 展開；回傳 dict，不記錄、不印出任何值。<br>`get_secret(name, env_path)`：先查環境變數，再查檔案。 |
| `config.py` | 讀取並驗證 `config/` 中的設定檔；缺少必要欄位或型別錯誤時，丟出 `ConfigError`，訊息包含檔名與欄位路徑。 |

`runner.run` 的規格：

- `argv` 必須是字串清單，不經過 shell。
- 環境變數：
  - 以目前的環境為基礎，移除 PLAN §5.3 列出的變數（`ANTHROPIC_API_KEY`、`OPENAI_API_KEY`、`CODEX_API_KEY`、`GEMINI_API_KEY`、`GOOGLE_API_KEY`、`GOOGLE_GENAI_USE_VERTEXAI`、`GOOGLE_CLOUD_PROJECT`、`METACULUS_TOKEN`），以及名稱以 `API_KEY`、`_TOKEN` 或 `SECRET` 結尾的變數。
  - `keep_env` 可以保留指定名稱的變數，留給各 CLI 登入時必要的變數，於 W4～W6 確認。
  - `RunResult` 記錄被移除的變數名稱（不記錄值）。
- 以 `start_new_session=True` 啟動。逾時時，先對整個程序群組送 `SIGTERM`，等待 5 秒，仍未結束再送 `SIGKILL`，並確認程序群組已經不存在。
- stdout 與 stderr 直接寫入檔案，不全部放在記憶體。
- `RunResult` 的欄位：`exit_code`、`timed_out`、`killed_signal`、`duration_s`、`started_at`、`finished_at`（ISO 字串）、`stdout_path`、`stderr_path`、`scrubbed_env_names`。

### 3. 設定檔（初始值）

數值取自 PLAN 指定的章節。PLAN 沒有規定的值，在檔案的 `_notes` 欄位中標示為「暫定」。

- `config/run_config_v2.json`：
  - 各線第 1 層與第 2 層的模型與推理強度（§5.3 的表格）；
  - 逾時：第 1 層 600 秒、第 2 層 1,200 秒；格式修復暫定 300 秒；
  - 第 2 層子代理上限 3 個；
  - 升級門檻：是非題 log-odds 差 1.0、截斷 [0.02, 0.98]、多選題機率差 0.25、市場 logit 差 0.7、市場價格 epsilon 0.005；
  - 截止時間：安全餘裕 20 分鐘、送出所需時間 5 分鐘、估時分位數 0.9；
  - `acceptance` 區塊：claude 用 Haiku、agy 用 `gemini-3.8-flash-low`、gpt 用 `gpt-6-astra` 搭配 `low`。實際可用的寫法標示為「待 W4～W6 確認」。
- `config/agg_v1.json`：是非題 log-odds 平均、extremizing 係數 1.0、截斷 [0.02, 0.98]；多選題幾何平均，平滑 ε = 0.02；三線等權。
- `config/quota_policy.json`：
  - agy：每週上限 0.60、第 2 層每題 0.05、`credits_must_be_zero: true`；
  - claude 與 gpt 的每週嘗試上限為 `null`，於 M2 量測後設定；
  - token 倍數上限 3；每線並行度 1；優先序依 §9。
- `config/tournaments.json`：主賽 `fall-futureeval-2026`（33121）、MiniBench `minibench`、測試區 `bot-testing-area`（32977）。所有 `submit_whitelisted` 都設為 `false`；另列出試驗場地類型。
- `config/submit_mode.json`：`{"mode": "local"}`。
- `config/players_enabled.json`：三線都設為 `true`。

### 4. 測試（`tests/`）

至少涵蓋：

- `jsonl`：多次追加不會覆寫；兩個程序同時寫入時每行都完整；不完整的最後一行在 strict 與非 strict 下的行為。
- `runner`：逾時會終止子程序與孫程序；環境變數的移除與保留；stdout 與 stderr 寫入檔案；`argv` 不是字串清單時丟出例外。
- `workdir`：權限為 `0700`；拒絕位於專案資料夾內的路徑；不會刪除 base 以外的資料夾。
- `timeutil`、`ids`、`envfile`：格式與邊界情況。`envfile` 只使用暫存檔，不讀取真正的 `.env`。
- `config`：實際的 `config/*.json` 都能通過驗證；欄位缺漏時的錯誤訊息正確。
